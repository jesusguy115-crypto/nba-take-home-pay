# 估算方法与情景输入

核验日2026-10-09。所有结果为公开数据下的情景点估计，未用真实个人税单校准，不能保证某个误差百分比。内部保存美分用于对账，对外默认四舍五入到1万美元。

## 1. 收入口径

`S` 为Spotrac 2026–27逐队Cash Table汇总现金薪资；同一球员多个付款记录按player ID合并。`P` 为2025–26同ID现金薪资。默认不加代言、投资、未知NBA Cup奖金或季后赛奖金。其他付款如Dead Money/Retained保留金额；无本季服务证据的部分只放假设居民地征税，不编造客场服务来源。这类结果不确定性更高。

默认基础工资按CBA标准合同24期、11月1日起半月支付的情景。实际合同可改期数及递延，签约金尤其可能不同。

| 项目 | 2026税年 | 2027税年 |
|---|---:|---:|
| 本赛季工资归属 `W` | `S/6` | `5S/6` |
| 全年工资代理 `G` | `5P/6 + S/6` | `S` |
| 本季归属比例 `r` | `W/G` | `W/G` |

找不到`P`时用`S`年化，明确标注；这可能高估首次进入NBA的新秀在2026年的其他工资。2027年化只是计算税率的假设，不预测2027–28合同。2026奖金输入加到当年`W`和`G`。可用`annual_income_2026/2027`覆盖全年收入代理。

每年先对完整`G`计算累进税、扣除和工资税，再乘`r`归属本赛季，避免把赛季的两小段各自享受完整低税档和扣除。它是年度平均税率的收入归属模型，不是个人真实税单，也不是工资增量税分析。

## 2. 客场地点和工作日

默认日历为2026-09-29至2027-04-11，每日最多一条记录。已定常规赛采用NBA公开场馆，出席是假设。训练营和季前赛默认球队城市；没有纳入真实异地训练营、季前赛、全明星或季后赛。

非比赛日规则可在`--ledger`查看：两个客场相隔不超过4天时按连续客场推定，搬迁日给目的地0.5天训练权重；较长间隔回球队城市；客场前后各一个旅行/训练日权重0.5，其余日权重1。剩余旅行权重不向非居民工作州分配，但仍留在整个日历分母中。此0.5权重是公开资料不足时的模型参数，**不是任何州法定的半天旅行税规则**。

`f_j = 税区j的加权日期数 / 赛季日历日期数`。州税年度计算使用同一赛季地理比例代理，两年不声称还原了各自实际履职记录；不同球队历史工资也未重新拼出旧赛季每一天。

各州法定分母、旅行日、伤病、额外服务以及来源税基并不完全一致。当前逐日账提高可解释性，不能据此宣称已完成所有税区法定申报。2026-10-09快照尚有30场联盟比赛未定、每队2场；更新数据后的覆盖与缺失场次由比赛明细动态推导，读取查询返回的 `schedule_coverage`，不沿用该快照的固定数量。没有生成虚构对手或虚构主客场。

## 3. 税额和抵免

美国按档案选择Single或MFJ工资情景，均采用标准扣除；公开已婚记录选择MFJ，资料未知则先用Single税表并提供MFJ对照。联邦、居民州和地方税按完整年度收入计算；工资税只计雇员份额。多数非居民州以全额州税乘来源比例近似，MA和CA来源附加税分别计算，免税/互惠规则另外处理。逐税区例外、反向抵免和来源在区域说明中。

州居民抵免一般取可抵外州税与本州对重复所得税额限额的较小值；依法允许合并限额的州单独处理。反向抵免记在工作州，不能又在居民州再扣一次。地方税抵免和州税抵免分开计算。Portland的SHS/PFA按各自政策独立限额；NYC普通居民地方税不自动获得外地城市抵免。

加州SDI、Paid Leave等按主雇佣覆盖州假设，不能每到一个客场州再加一份全年保险。球队代付或私人等价计划未确认，采用法定最大雇员份额。Denver OPT按每月至少500美元来源工资的5.75美元情景，年度代理复用本季月份并随年度归属；数额小但不冒充实际工资单。

### 跨境

美国球队短期加拿大履职，假设美国条约居民并满足美加雇佣条款，最终加拿大所得税为零；不会凭空加15%“加拿大税”。该来源工资仍纳入美国联邦外国来源收入抵免限额的模型分子。

英国、法国、墨西哥按实际海外履职日期所在税年，对`S × 该境外税年加权天数 / 赛季日历天数`计算一次境外税，直接计入本季该年税额，避免再乘发薪归属比例。杯赛奖金未提供单独境外来源事实，默认不作海外分摊。美国FTC使用对应年度联邦税与境外来源收入比例限额，并限制在本季归属联邦税内。该算法仍以服务年近似相关工资确认年，实际跨年发薪及结转可能改变结果。英国税年始于4月6日；复杂跨年覆盖不能重复使用当地年度税档。

法国税表采用明确标注的最近已核定年度代理；英国按英格兰税档；墨西哥按25%毛收入路径。固定汇率为2026-10-08快照，非真实税年平均汇率。州级境外抵免没有全面模拟，海外球员估值可能偏保守。

猛龙默认**安大略居民、非美国公民、符合赴美雇佣协定豁免且加拿大社保覆盖成立**的情景，计算加拿大联邦、省税、CPP/EI和美国州/地方税抵免。此设定不声称个人实际公民身份；美国公民或不符合协定的人需单独计算双重申报，不能套此结果当事实。

## 4. 从税前到税后

```
税后合同收入 = Spotrac现金薪资 + 指定奖金
              − 联邦所得税 − 雇员工资税
              − 居民州/省税 − 客场州税 + 居民州抵免 + 工作州反向抵免
              − 居民地方税 − 客场地方税 + 居民地方抵免
              − 其他雇员强制缴款 − 境外税 + 境外税收抵免
```

返回的`components_usd`中抵免为负税额，所有分项相加等于`estimated_tax_usd`，受美分舍入影响可能差数美分。`gross_usd − estimated_tax_usd = estimated_net_usd`。2027未知税档、工资上限等沿用2026；已验证的IN/NC税率、Portland门槛和CO保险变化单独应用。

## 5. 用户情景文件

`python3 scripts/take_home.py 'Yang Hansen' --scenario /absolute/path/scenario.json --explain`

支持字段：

| 字段 | 含义 |
|---|---|
| `filing_status` | 美国`single`/`mfj`；加拿大`individual_canada`，默认按档案选择 |
| `spouse_wages_2026`, `spouse_wages_2027` | 用户指定各年的配偶工资，仅美国MFJ支持；缺省不纳入配偶工资，不代表实际为零 |
| `residence_state` | 已覆盖美国州/特区代码；TOR默认ON，跨美加居民地转换不支持直接覆盖 |
| `residence_city` | 已覆盖NBA城市英文名；空字符串表示假设无居民城市税，并非证明郊区无任何税 |
| `annual_income_2026`, `annual_income_2027` | 该年纯工资收入代理，不能小于本赛季当年分配额 |
| `cup_bonus_usd` | 已知/明确假设2026年支付的杯赛额外奖金，默认为0；未单独建杯赛奖金的各地来源规则 |
| `agent_fee_rate` | 如0.04，现金流额外扣除情景，默认0，不假定可税前抵扣 |
| `escrow_rate` | 明确指定的临时托管比例，默认0；不当作永久税负 |
| `duty_day_overrides` | 日期地点覆盖列表，结构见下 |

例如**纯假设**的G联赛工作日覆盖，不代表杨瀚森真实安排：

```json
{
  "duty_day_overrides": [
    {
      "start": "2026-11-10",
      "end": "2026-11-12",
      "country": "US",
      "state": "CA",
      "city": "Stockton",
      "activity": "g_league_game",
      "evidence": "用户指定的假设情景"
    }

```

活动支持`game/practice/rehab_team/g_league_game/g_league_practice/postseason_duties`（来源权重1），`rehab_private/injured_no_duties/travel_only`（来源权重0）。覆盖同日替换原记录，不重复算NBA与G联赛；跨原日期范围可增加日历日。各州伤病分母例外未逐个实现，不能把权重0理解成依法从全部州分母删除。工资金额不会因这些覆盖自行减少。

不支持税区会明确停止该定制计算，不会静默按零税。已覆盖30支NBA队所在州/城市及CA/GB/FR/MX客场国家；自定义异地训练和G联赛若在其他州，需要先补税则。


## 6. 全体球员的申报情景与家庭税归属

婚姻事实来自独立的520人档案，所有实际报税方式均为unknown，除非之后获得合适公开证据。公开已婚记录只用于选择默认MFJ情景，未知记录不强行填single。每名美国球队球员都预计算Single和MFJ、只纳入球员工资的两个数；加拿大采用个人申报模型。没有公开税单回测，不把两情景差值当全部误差或承诺估值区间。

有配偶工资输入时，设球员全年工资代理为G，配偶工资为W，家庭工资H=G+W，球员比例q=G/H。夫妻共同联邦/居民州/居民地方所得税在H上按MFJ计算，归属球员的基数为家庭税×q。Social Security按两人的工资各自适用上限，普通Medicare逐人计算，Additional Medicare先对家庭合计按250,000门槛计算，再按工资比例归属。不会把配偶的一份社保税扣到球员工资上。

球员客场来源收入=G×该税区工作日比例；在家庭税率计算里，来源比例为该金额/H。配偶假设全在同一居民地履职，不能随球员客场行程分摊。球员客场税及由这些税产生的各级抵免归属球员；上述家庭居民税乘q的分配和抵免来源单列，保证对账。境外税仍只使用球员合同来源报酬，联邦境外抵免限额以家庭联邦税和家庭工资作比例基数。

计算出的年度球员税负再按本赛季工资/球员全年工资代理归属到赛季。这个工资比例分配是模型约定，不是夫妻私人税单必须采用的分担规则。配偶有自雇、资本所得、异地工资、不同居民身份，或选择MFS时，不能强塞进本工资模型，需要进一步补充规则。

2026/2027两年均采用同一申报情景；实际婚姻变化、离婚或税年末状态差异需按年处理，尚未自动推断。低收入家庭的子女、教育、已退役配偶等专项抵免没有全面纳入，不能称本模型涵盖家庭报税表所有项目。
